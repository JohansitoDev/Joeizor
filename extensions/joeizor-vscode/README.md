# Joeizor Language for VS Code

Extensión local para archivos `.je`, con resaltado basado en los scopes de color
Ruby habituales de TextMate y el icono de Joeizor para todos los archivos `.je`.

Para probarla desde VS Code, abre esta carpeta del proyecto y ejecuta
**Debug: Start Debugging** con una configuración de Extension Host, o instala
la carpeta con la herramienta `@vscode/vsce` empaquetándola como `.vsix`.
Selecciona **Joeizor File Icons** en `Preferences: File Icon Theme`.
